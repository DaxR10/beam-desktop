# Beam Designer

A Tkinter desktop beam design tool that plots shear, moment, and deflection, checks bending stress and deflection, and suggests a passing section.

## Requirements

Install Python 3.10 or later, then install the required packages:

```bash
pip install numpy matplotlib
```

Tkinter is included with most Python installations. On macOS, use `python3` and `pip3` if needed.

## Run

Open this folder in VS Code and run:

```bash
python app.py
```

On macOS, use `python3 app.py` if `python` is unavailable.

Use the File menu to save/open a beam. Use the buttons to export CSV results or a PDF calculation sheet.
